Privacy Policy

Minecraft Backups is a privately operated application that uses Google Drive to store Minecraft server backups.

Google Drive Access

The application requests permission to create, access, and manage files created through the application in the authorized Google Drive account.

Data Storage

Minecraft backup archives are stored in the authorized user's Google Drive account.

Data Sharing

Backup files and Google account data are not sold or intentionally shared with third parties.

Data Retention

Older backup archives are automatically removed according to the configured backup retention policy. The user may also remove files directly from Google Drive.
